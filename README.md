# KKB Site Diary privacy pages

Status: sample-only notice prepared for public hosting, 25 October 2026. Publication is authorised by Yoshi. Verify the Pages deployment before treating the URLs below as live.

This separate repository holds only the text-only privacy notice, deletion instructions and their page assets/documentation. The pages have no database, login, JavaScript, analytics or automation service code. GitHub can retain host request logs. Do not add credentials, project records or captured messages.

Future staff-role controls are not presented as installed. Publication does not complete a legal assessment, provider/account review or live-use approval. Keep those reviews in the private project records, not on the public pages.

SharePoint remains the controlled document home. The older SharePoint draft is not this published version. Keep the controlled copy and website in step when changes are made.

## Local preview

Run `python3 -m http.server 8766 --bind 127.0.0.1 --directory .` from this folder. Open `http://127.0.0.1:8766/` for the notice and `http://127.0.0.1:8766/data-deletion/` for the deletion instructions. Stop the server when finished. No installation is needed.
